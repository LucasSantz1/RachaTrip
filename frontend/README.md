# RachaTrip - frontend

Aplicação Next.js (mobile-first) do RachaTrip.

- `npm ci` instala as dependências.
- `npm run dev` inicia o servidor de desenvolvimento em http://localhost:3000.
- `npm run build` gera o build de produção.

As chamadas a `/api/*` são encaminhadas ao Django pelo rewrite do Next, usando `API_INTERNAL_URL`.

Veja o [README da raiz](../README.md) para a visão geral do projeto.
